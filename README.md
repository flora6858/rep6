# Weather Diary

**Автор:** [Перков Никита]
**Язык:** Python 3.x

## Описание

GUI-приложение "Weather Diary", позволяющее добавлять, просматривать и фильтровать записи о погоде, сохранять данные в JSON и использовать Git.

## Возможности
* Ввод даты, температуры, описание погоды, наличие осадков
* Можно добавить записи и есть возможность фильтрации по дате, по температуре
